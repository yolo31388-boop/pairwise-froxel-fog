# pairwise-froxel-fog

体积雾里的手电光在光源移动时拖出一条旧光柱，froxel 的历史重投影只按相机运动算，没算光源变化；深度切片按指数分布但每帧重排，froxel 索引和上一帧对不上；半分辨率雾在深度不连续处双边上采样，角色边缘出现光晕；阴影采样只取一张级联，远处光柱穿墙；多次散射近似用固定各向异性，逆光时雾发黑；蓝噪声抖动每帧换序列但没做时域累积，静止画面也在闪；透明介质和雾共用一张 froxel，玻璃后面的光柱被加倍；异步 compute 写 froxel 与主渲染读之间没有 UAV barrier；光源数量超上限后直接截断，最后一盏灯的光柱突然消失；雾密度在相机进出水面时没切换介质，水下出现空气雾。render/volumetric_fog.py 是核心，tests/test_volumetric_fog.py 15个红。要修的是：重投影同时算光源运动；切片布局跨帧稳定；上采样按深度联合；阴影取可见级联并做遮挡；各向异性随视角插值；蓝噪声配时域累积；透明与雾分通道；compute 后插 barrier；超限光源做重要性合并；进出水切换介质参数。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
